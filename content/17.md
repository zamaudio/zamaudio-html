While Linux doesn’t have a piece of software that rivals the usability of [Pro Tools](https://www.digidesign.com/index.cfm?navid=507), you can still do high-quality audio recording with [Ardour DAW](https://ardour.org), a professional digital audio workstation. written for linux/osx. Also, you can use your linux machine as a virtual synthesiser by using VST instruments and recording directly into Ardour DAW.

Currently, Ardour DAW doesn’t support 64-bit operating systems with Windows VST support, so you will need a 32-bit OS.  
Download an x86 (32-bit) version of [Ubuntu Linux](https://www.ubuntu.com/getubuntu/download) and install it.  
Follow the guide to [Ubuntu audio installation/configuration](https://help.ubuntu.com/community/UbuntuStudioPreparation).  
Then [download](https://ardour.org/download) Ardour DAW source code and follow the instructions on how to build it with [Windows VST support](https://ardour.org/building%5Fvst%5Fsupport).
